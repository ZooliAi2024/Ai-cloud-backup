Privacy Policy

Effective date: November 25, 2026

1. Application Purpose

Rashino AI Cloud Backup is a private, single-user application for encrypted project backups and disaster recovery.

2. Google User Data Access

The application accesses Google Drive data through OAuth 2.0 with the account owner's authorization. Depending on the permissions granted, access may include file contents, filenames, folder information, file metadata and storage information.

3. Use of Google User Data

Google Drive data is used solely to create, upload, locate, verify, manage and restore authorized backups. It is not used for advertising, profiling, unrelated analytics or artificial intelligence model training.

4. Data Storage and Protection

Backup archives are encrypted on the owner's infrastructure using Rclone Crypt before being uploaded to Google Drive. Backup files, operational logs and OAuth credentials may be stored locally on the owner's authorized systems.

Access credentials and encryption keys are protected through restricted access and file permissions.

5. Data Sharing

The application does not sell Google user data or disclose it to advertisers or unrelated third parties. Google Drive is used as the authorized cloud storage service.

6. Data Retention and Deletion

Backup data is retained according to the owner's backup and recovery requirements. The owner may delete backup files and associated local records when no longer required.

7. Revoking Access

The account owner can revoke the application's Google authorization through their Google Account security settings. Revocation prevents further authorized access but does not automatically delete previously stored backups.

8. Google API Compliance

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.

9. Documentation Website

This documentation website does not provide a login form or collect backup files. Website hosting is provided by GitHub Pages and is subject to GitHub's applicable privacy practices.

10. Contact

Questions about this application may be directed to the application owner using the support contact displayed on the Google OAuth consent screen or through the application's GitHub repository .

11. Policy Updates

This policy may be updated to reflect changes in application functionality or applicable requirements.
